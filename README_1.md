# Murphy’s Law

*Anything that can be taxed, will be — even if you haven’t sold it yet.*

A web version of a tax law presentation on mark-to-market taxation: economic basics, legal barriers (*Murphy v. United States*, 992 F.2d 929 (9th Cir. 1993); *Moore v. United States*, 602 U.S. 572 (2024)), and political barriers, including why return variation matters under accrual taxation (Brennan, *The Structure of Accrual Taxation*, draft Jan. 2025).

Everything is in one self-contained `index.html` (figures are embedded), so no build step is needed.

## Navigation

- **← / →**, Space, or swipe: previous / next slide
- **O**: overview of all slides
- **Home / End**: first / last slide
- Click a figure to enlarge it
- Each slide has its own link (`#1`, `#2`, …)

## Publishing on GitHub Pages

1. Create a new repository and upload `index.html` (and this README).
2. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", pick `main` and `/ (root)`, and save.
3. The site will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.
